# 期末星图 · 单机生产优化规划

面向：**自己长期使用的 self-hosted 生产环境**（Docker 或 `next start`），不对全校/公网多租户开放。  
不包含：PostgreSQL 多用户、分布式队列、对象存储、SaaS 登录。

本文是实现清单。每一条都对应仓库中的具体改动。

---

## 目标

1. 关页面、休眠、反代超时后，分析任务仍能跑完或留下可重试的失败态。
2. Agent 从资料里抽出更多可追溯考点、题型、易错点和可练题目；课件（PPTX/DOCX）不再只能靠 Files API。
3. 数据目录有容量上限、紧凑落盘、用量可查、可自动备份。
4. 计划任务能跳进对应课程练习；上传/删除/分析过程可读、可撤销、可拖放。
5. 容器健康检查反映磁盘就绪；密钥不进日志；CI 覆盖生产布局冒烟。

额度与费用不作为约束：宁可多抽、多问、多模态，也不再为省 token 降低分析深度。

---

## A. Agent 分析能力

| ID | 项 | 做法 |
|---|---|---|
| A1 | 更深的考点与题目 | 单份资料最多 16 个考点、16 条题型、10 道原创新题、10 条学习动作；综合最多 12 个高频点、10 道诊断题、**最多 20 份资料** |
| A2 | 更完整的题目结构 | 题目增加难度 1–5 与易错点；单选强制 ≥4 选项且答案落在选项上 |
| A3 | 考试上下文 | 把考试日期、剩余天数、优先级、教师、学期一并交给模型（仍标明不可信、禁止当指令执行） |
| A4 | 证据更可追溯 | 摘录上限 120 字；鼓励页码/幻灯片号；本地抽到的正文与 Files 引用同时发给模型 |
| A5 | 课件/讲义本地抽文本 | PPTX 抽幻灯片 XML，DOCX 抽 document.xml；OLE 的 ppt/doc 做纯文本兜底；与 PDF `unpdf` 并列 |
| A6 | 更长窗口 | 模型超时 180s，输出上限 12000 tokens；PDF 本地抽字 40 万字 |
| A7 | 分析提示词 | 按期末试卷/课件/题库分别强调：高频题型、计算步骤、定义定理、易混点；禁止抄原题全文 |

## B. 运行时：后台任务

| ID | 项 | 做法 |
|---|---|---|
| B1 | 分析后台化 | `POST /analyze` 在 `background: true` 时 202 立刻返回；worker 持有重请求槽并写回状态 |
| B2 | 综合后台化 | 课程综合同样支持后台；工作区公开 `processingJobs` |
| B3 | 进度阶段 | `queued` / `extracting` / `calling-model` / `saving`；前端轮询工作区 |
| B4 | 关页不丢 | 状态落在 `分析中` + lease；进程 SIGTERM 时把未完成任务标失败以便重试 |
| B5 | 测试兼容 | 不传 `background` 时仍同步等待（集成测试与 HTTP 冒烟保持 200） |

## C. 数据与运维

| ID | 项 | 做法 |
|---|---|---|
| C1 | 上传总容量 | 默认 8GB（`FINALE_MAX_UPLOAD_BYTES`），超限明确 507 |
| C2 | 生产紧凑 JSON | `NODE_ENV=production` 时 `workspace.json` 不 pretty-print |
| C3 | 用量账本 | 累计 input/output tokens 与请求次数，个人资料页只读展示 |
| C4 | 自动备份 | Compose `backup` 服务每日把数据卷打 tar 到 `finale-backups`（只读挂载，不中断应用） |
| C5 | 健康检查 | 镜像 HEALTHCHECK 改为 `/api/health`（真实写探测） |
| C6 | 密钥打码 | 请求头 `x-openai-api-key` 不出现在错误日志；instrumentation 红处理 |
| C7 | CI 冒烟 | typecheck / test / build 之后跑 `http-e2e-smoke.mjs`（复用刚产出的 standalone） |
| C8 | 优雅停机 | `instrumentation.ts` 注册 SIGTERM：停止接新后台任务，失败未完成分析 |

## D. 产品闭环与体验

| ID | 项 | 做法 |
|---|---|---|
| D1 | 任务跳转练习 | 计划里「练习/回顾」打开对应课程练习页，并尽量按知识点过滤 |
| D2 | 任务完成与跳转分离 | 完成勾选与「去练习」分开，避免误触整卡完成 |
| D3 | 拖放上传 | 资料区支持拖放本地文件 |
| D4 | 应用内确认 | 删除课程/资料用对话框，不用 `window.confirm` |
| D5 | 分析进度文案 | 资料卡与 Agent 卡片展示当前阶段，允许离开页面 |
| D6 | 题目难度 | 练习页展示难度与易错点（提交后揭示） |

## 明确不做

- 多租户账号、Postgres RLS、对象存储
- 把服务默认绑到 `0.0.0.0` 对公网开放
- 为省钱降低分析深度或关闭视觉输入

## 验收

- `npm test` 与 `npm run typecheck` 通过
- 上传 PPTX/DOCX 在兼容网关拒绝 Files 时仍能靠本地抽文本分析
- 浏览器 `background: true` 分析返回 202，轮询后资料变为已分析或失败
- 生产 JSON 为单行；超容量上传 507
- Docker HEALTHCHECK 访问 `/api/health`
